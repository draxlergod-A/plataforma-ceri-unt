Una edición, paso a paso

Del borrador
a la biblioteca.

Un proceso sencillo para cuidar el contenido y su presentación.

01

Define el informe

Completa el título, el equipo autor, el ámbito y un resumen breve. Cada edición tiene un enlace propio.

02

Prepara la portada

Elige una foto para la portada editorial o sube un diseño completo. Describe la imagen para facilitar la lectura accesible.

03

Construye las páginas

Añade texto, imágenes, citas, cronologías o fuentes. Puedes duplicar páginas y cambiar el orden, o subir varias páginas ya diseñadas de una vez.

04

Revisa y publica

Comprueba la vista previa del libro. Guardar conserva el estado actual; publicar hace que la edición aparezca en la biblioteca. Los borradores siguen disponibles en este panel.

↻

Cuida tu trabajo

El editor recupera cambios en este navegador. Cada guardado crea un respaldo en el servidor. Descarga también una copia desde tu biblioteca.

↗

Comparte la edición

Después de publicar, abre “Ver en la web” para comprobarla. Mientras el sitio funcione en tu computadora, esta debe permanecer encendida para recibir nuevas publicaciones.
